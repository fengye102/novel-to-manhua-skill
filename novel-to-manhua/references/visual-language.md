# 视觉语言与样图索引

## 默认 Q 版造型

参考 [novel-comic-promo 的 Q 版约束](https://github.com/CYU1102/novel-comic-promo/blob/main/SKILL.md)所强调的“大头、短肢、表情清楚、画面简约”，但不借它的人物设定、页数或画布尺寸。本 skill 以本目录样图为造型证据：全身人物默认约 2～3 头身，头大而圆、躯干短小；眼眉嘴与姿态可夸张，脸、头发和衣服主体仍保留细节。短肢不是一般 Q 版的圆柱手脚，而是从袖口/裤脚伸出的黑色单笔或折线，手为实心黑圆点。画面保持清爽，普通页减少装饰、复杂背景与高饱和特效；关键道具、情绪转折和必要的场景光影才重点刻画。全身人物若呈普通动漫或写实头身比，应在无字底图阶段返工。用户明确指定其他风格时按当次要求调整。

## 先识别截图边界

根目录原图大多是 864×1920 或 291×647 的手机截图，但实际漫画主体约为 3:4 竖版，居中嵌在屏幕里。不得把手机时间、电量、底部导航线、灰黑背景空带或平台页码直接绘入新漫画。输出尺寸由用户和平台决定；未指定时用 3:4，例如 1200×1600，保留画面边界内的安全区。

## 从图到可执行的版式规则

- **阅读顺序**：连续的镜头遵循左到右、上到下；斜切格也须让视线自然流向下一格。用远景交代空间、中景交代动作、特写捕捉转折，不连续堆满人脸特写。
- **页内节拍**：普通页以 2～3 格为起点；转折可用大格或单幅，动作拆解可增加小格。每页最后一个格子回答当前悬念或制造下一页问题，避免每页都用同一种空喊式悬念。
- **后配文字**：先绘制没有任何文字、空白气泡或旁白框的画面，只预留安全区；确认画面后，另起排版层加白底黑边旁白框及圆润、锯齿或自由形气泡，再填入脚本中的准确中文。保持字形可辨、行距充足；一个框只传达一个意思。优先缩句和拆框，而不是无限缩字号。用户指定横排简体中文时维持统一阅读方向。
- **颜色与光线**：现代情感和亲子偏暖，喜剧 Q 版背景偏中性且情绪高点可强化对比，古风偏灰褐。整套先设主色与角色代表色，再按剧情调光，不让每页像不同画师。
- **角色一致性**：头身比、眼型、刘海、服装配色和道具必须可追踪；Q 版允许夸张变形，但同一情境里不能莫名换脸、换衣、变年龄。
- **Q 版不是只缩短四肢**：完整人物先看轮廓是否是偏大的圆头、短小躯干、约 2～3 头身，再看眼眉嘴和姿态是否能传达当格情绪；近景看不见身体时仍用圆脸、大眼或夸张眉嘴保持 Q 感。普通页用简单背景突出人物和线索，别让耀眼特效掩盖表情。
- **省笔画法是核心**：把细节预算放在脸（眼睛、表情、头发）、衣服主体轮廓、道具和有光影的背景；露出的四肢刻意降到火柴人层级。袖口、衣摆或裤脚之后不继续画圆柱形手臂/小腿，而以一根黑色细直线或至多一个折角表示肢体；上肢末端用无手指的实心黑圆点表示手。近景中这种精细与简陋并存的反差也要保留，不能因画面放大就自动补成正常手掌、肘膝或肌肉。
- **可读而非解剖正确**：线条起点属于正确人物，朝向能读懂伸手、举杯、指物等动作；圆点触及应触及的道具。修复悬空黑点、穿脸连线或多余肢体；不要把所有“怪手”重画成普通漫画手。被衣服或构图遮住的肢体不硬加线，避免每格机械地露出四根火柴线。

出图时可直写：`精绘大头、发丝、表情、外套和客厅光影；手臂与腿是从衣服边缘伸出的单笔黑色火柴线，手只是一颗实心黑圆点；故意不画手指、手掌、肌肉和关节；保留精细背景与极简肢体的反差。` 这比只说“Q 版”“细线四肢”更能锁住样图的省笔效果。

## 选择方法

读完原文先用一句话定基准，例如“现代情感：暖日光、精绘脸与室内、火柴线四肢和黑圆点手、对白克制、以眼神特写推进”，然后在 `visual-bible.md` 填入[人物视觉卡](character-cards.md)对应的可见锚点。若同一故事有喜剧与悲伤段落，在同一套角色和线条下调整镜头、表情与灯光；不要在两页之间切换成完全不同的基准。
